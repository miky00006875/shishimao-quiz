# 柿柿猫 · 互动心理测试 H5

> 测一测｜你是哪只“柿柿猫”？解锁你的专属IP人设 🍅🐱

一套面向年轻女性用户的轻松治愈、可爱俏皮互动心理测试，基于 12 款潮玩 IP（柿子 + 猫咪元素系列）性格设定。

## 特性
- 📱 移动端优先，粉橘色调、治愈手绘风
- 🎴 吸睛封面：标题 + 12 款形象缩略图拼贴 + “开始测试”按钮
- 📝 8 道题目逐页展示，底部进度条（第 X/8 题）
- 🏆 提交后生成专属结果海报：IP 名称（emoji + 加粗）+ 性格解析 + 专属 Slogan + “去同款 IP 超话找组织 #柿柿猫#”
- 💬 页面底部互动引导：“做完记得 @你的姐妹来看看，你们是不是同一款柿柿猫！”
- 🧮 计分：按每题指向的 3 款 IP 加权统计，出现次数最多者胜出（含平局优先级）

## 文件
- `index.html` —— 单文件可直接分享的 H5 互动测试页面（已内嵌全部数据）
- `data.json` —— 完整结构化数据（12 款 IP 设定、8 题题目与映射、计分规则、结果文案），便于二次开发

## 本地预览
直接用浏览器打开 `index.html` 即可；建议用移动端视图（DevTools 设备模拟）查看最佳效果。
